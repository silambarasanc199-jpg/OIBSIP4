NEXCALC — Futuristic Calculator

A responsive and interactive calculator created as part of the Oasis Infobyte Web Development & Designing Internship.

🚀 Project Overview

NEXCALC is a modern calculator application designed with a futuristic interface and built for smooth use across desktop and mobile devices.

✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Decimal calculations
- Clear (AC)
- Delete (DEL)
- Equals operation
- Keyboard support
- Responsive mobile layout
- Futuristic user interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Responsive Media Queries
